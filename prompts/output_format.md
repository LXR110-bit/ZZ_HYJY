# 会议纪要输出格式约束

## 输出结构（必须按此顺序）

```
# 会议纪要：{会议主题}

**时间**：{会议时间}
**参会人**：{参会人员列表}
**会议类型**：{周会/评审/决策/同步/其他}

## 一、会议目标
（一两句话说明本次会议要解决什么问题）

## 二、关键讨论点
### 1. {议题1}
- **背景**：（为什么讨论这个）
- **讨论要点**：（讨论了哪些内容，列 3-5 点即可，不要逐字罗列）
- **结论**：（最后的共识或决定，没结论就写"未达成一致"）

### 2. {议题2}
...

## 三、决策事项
| 序号 | 决策内容 | 决策人 | 影响范围 |
|------|---------|-------|---------|
| 1    | ...     | ...   | ...     |

## 四、待办事项（Action Items）
| 序号 | 任务 | 负责人 | 截止时间 | 状态 |
|------|------|-------|---------|------|
| 1    | ... | ...   | ...     | 待开始 |

## 五、未解决问题
（列出悬而未决的问题，后续跟进）

## 六、备注
（其他需要记录的信息）
```

## 写作规范

1. **客观陈述**：用"触达组成交率是对照组 2.1 倍"，不用"效果显著"
2. **归属清晰**：每个 Action 必须有明确的负责人（不能写"大家一起"）
3. **时间具体**：截止时间必须是明确日期（"本周五" → "2026-05-16"），不用相对时间
4. **结论明确**：每个议题必须有结论（"已达成 X 共识" / "未达成共识，X 跟进" / "延后至 X 讨论"）
5. **详略得当**：
   - 讨论要点：3-5 个核心点即可，不要逐字记录
   - 决策 / Action：必须完整保留，不能省略
6. **避免主观词**：不用"效果显著"、"非常好"、"明显"等主观评价

## 摘要版（群消息）要求

3-5 条，每条一行，格式：
```
✅ {结论/决策}（@责任人 DDL）
```

例子：
```
📋 周会纪要已生成

✅ 聚合回收品类本周 GMV 同比 +15%，继续保持当前投放策略
✅ 组装机召回 push 实验 P0 通过，下周推全量（@张三 2026-05-20）
✅ 新品牌入驻评审未达成一致，待法务意见（@李四 2026-05-16）

📄 完整版文档: {url}
```
