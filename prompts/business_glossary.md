# 转转回收业务术语表

> 供会议纪要 AI 纠正语音识别错误、理解业务语境用。术语表越完整，纪要越准确。

---

## 一、业务主体

- **转转回收**：主业务（C2B 二手回收）
- **聚合回收**：核心业务模式，简称"聚回"（❌"具回"/"剧回"/"居回"）
- **对标友商**：爱回收、找靓机、红布林、胖虎

## 三、业务模式与链路

**模式：**
- C2B：用户卖给转转（回收）
- B2C：转转卖给用户（二手售卖）
- B2B：B 端批发

**用户动线（回收流程）：**
```
询价 → 机况页 → 估价页 → 下单页 → 揽收 → 质检 → 成交 → 结算
```
对应指标：机况页 UV → 估价 UV → 下单 UV → 成交量 → 成交 GMV

**常被误识别术语对照：**
| 语音识别错误 | 正确写法 |
|---|---|
| 具回、剧回 | 聚回 |
| 专利率、转为率 | 转化率 |
| 长效率、成家率 | 成交率 |
| 机况页 | 机况页（不是"机况"+"页"） |
| GMB、JMV | GMV |
| 币类、品累 | 品类 |
| 汉兜、含抖 | 抖音 |
| 付费刘 | 付费流 |
| B2b、b2c | B2B、B2C（大写） |
| 组装机 | 组装机（不要写成"装机"） |
| 塘羊头卖狗肉 | 挂羊头卖狗肉 |

## 五、核心指标

**流量指标：**
- DAU（日活跃用户）、MAU、WAU
- 回收入口 UV、品牌页 UV
- 机况页 UV、估价 UV、下单 UV、成交量
- PV、曝光量、点击量

**转化率：**
- 机况页 → 估价 转化率
- 估价 → 下单 转化率
- 下单 → 成交 转化率（最重要的定价/履约信号）
- 整体转化率 = 成交量 / 机况页 UV

**渗透率：**
- 聚合回收渗透率 = 回收入口 UV / DAU
- 真实渗透率（剔除重复访问后的净渗透）
- 历史高点/低点对比（如"回升至 0420 水平"指回到 2026-04-20 那周水平）

**金额指标：**
- GMV（成交总额）
- 客单价、件单价
- ARPU（每用户平均收入）
- 净 ROI（剔除补贴/通道费后）

**活动/投放指标：**
- 触达率 = 实际送达 / 人群包总量
- 点击率（CTR）
- 核销率（领券/核销实际使用率）
- 退订率、客诉率

## 六、实验与数据分析术语

**AB 实验：**
- test_id（实验 ID）、group_name（分组名）
- A 组（对照组）、B 组（实验组）、A/A 基线
- 实验组 / 对照组 / 未触达组（三组对比是常见设计）
- P0 / P1 / P2 通过（P0=北极星指标，P1=深度下钻指标，P2=长尾指标）
- 显著性（p<0.05）、置信区间
- 流量还原倍数

**活动 / 召回：**
- 复卖（同用户二次卖货）
- 召回（流失/沉默用户唤醒）
- 触达（push/短信等触达用户）
- 种子池（估价未下单的高意向用户，用于后续 push 召回）
- 加价券（回收补贴，区分"领券率"和"核销率"）
- MA（Marketing Automation，自动化营销规则）

**时间窗口：**
- T+1 / T+3 / T+7 / T+30（累计成交周期）
- 衰减曲线（召回后用户转化的时间衰减）

**用户分层（生命周期）：**
- 导入期、成长期、成熟期、沉默期、流失期
- 跨品类分析常用"历史 A 品类成交 × 目标 B 品类估价"关联

## 七、常用数据表（Hive / Spark）

- 订单表（含 order_source，`order_source not in (66)` 排除内部订单）
- 埋点表（双重时间过滤：dt 分区 + 实际时间字段）
- 标签表（活动前一天的分区）
- 毫秒时间戳字段需 `/1000` 再 `from_unixtime`
- 品类品牌映射表

## 八、分析框架 / 方法论常用词

- 数据三层框架：全局扫描 → 问题定位 → 深度分析
- 横竖坐标法：横向对比 + 纵向拆解 + 交叉分析 + 时间对比
- 品类路径归类：搜索依赖品类 / 首页金刚位引导品类 / 平衡品类
- 新品活动四层结论：定性 → 选品规律 → 种子池机会 → 品牌溢出
- 跨品类召回 SOP：实验设计 → 基线校验 → 全链路漏斗 → 多维归因 → MA 固化

## 十、约定俗成的简称与黑话

- "做成交" / "跑成交"：跑成交数据分析
- "跑数"：执行 SQL 取数
- "拉数据" / "拉明细"：从数仓导出数据
- "圈人" / "圈选人群"：用标签筛选目标用户
- "打标签"：为用户/订单加属性标签
- "上 push" / "发 push"：推送通知
- "AB 跑通"：实验达到统计显著
- "推全" / "全量"：实验成功后推给所有用户
- "看盘" / "大盘"：整体数据
- "上线"、"下线"：功能/活动的启用与停用
- "对齐"：团队间同步信息达成共识
- "串讲"、"过一遍"：逐项汇报
